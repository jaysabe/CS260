# Project 4 : C++ Automated Harvester

## Project Overview
This project is focused on developing a C++ program to manage planting, harvesting, and pruning plants in an automated food-growing factory. The goal is to efficiently handle a large list of plants while ensuring the data structure can be traversed in order. The primary objective is to learn how to implement and use a Binary Search Tree (BST) without relying on any premade BSTs or other data structures. Additionally, this assignment aims to enhance familiarity with using char* for string data instead of std::string.

## Project Objectives
#### 1) Implement a Binary Search Tree (BST):
- Manually implement a BST from scratch. You cannot use any premade BST or any other data structure.
- The BST should efficiently handle the planting, harvesting, and pruning of plants.

#### 2) Match Expected Output:
- Ensure that your program’s output matches the provided expected output files exactly. This includes spelling, whitespace, and punctuation.

#### 3) Evaluate Design and Implementation:
- Your program will be evaluated based on how well it runs (within 5 seconds) and the quality of its design and implementation.
Refer to rubric.txt for detailed evaluation criteria.
